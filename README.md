# GoProject
A RESTful backend system for a collaborative project management application. The platform enables users to create dedicated workspaces, invite team members, and manage projects and tasks within an isolated environment. Designed to support team collaboration, the system provides secure workspace-based access control while maintaining a scalable and maintainable backend architecture.

# Features
- Workspace Management
- Create and manage multiple workspaces.
- Isolated project environments for each team.
### Team Collaboration
- Invite users to join a workspace.
- Manage workspace members and permissions.
### Project Management
- Create, update, and delete projects.
- organize multiple projects within a workspace.
### Task Management
- Create and assign tasks.
- Update task status and progress.
- Track project activities through structured task management.
### Authentication & Authorization
- Secure user authentication.
- Role-based access control for workspace members.

# Tech Stack
- Backend: Go (Fiber)
- Database: PostgreSQL
- ORM: GORM
- Authentication: JWT
- Architecture: REST API
